Imperative vs Declarative UI Programming

Imperative JavaScript (Vanilla JS)

0
// Select DOM elements
const counterElement = document.getElementById('counter-value');
const incrementBtn = document.getElementById('increment-btn');
const decrementBtn = document.getElementById('decrement-btn');
const resetBtn = document.getElementById('reset-btn');

// Initialize counter value
let count = 0;

// Update UI function
function updateUI() {
    counterElement.textContent = count;
    counterElement.style.color = count > 0 ? '#2c3e50' : count < 0 ? '#e74c3c' : '#2c3e50';
}

// Add event listeners
incrementBtn.addEventListener('click', () => {
    count++;
    updateUI(); // Manually update UI after state change
});

decrementBtn.addEventListener('click', () => {
    count--;
    updateUI(); // Manually update UI after state change
});

resetBtn.addEventListener('click', () => {
    count = 0;
    updateUI(); // Manually update UI after state change
});

// Initial UI update
updateUI();

Imperative Approach Characteristics:

  • You explicitly describe how to achieve the result
  • You manually select and update DOM elements
  • You're responsible for managing state and UI synchronization
  • Code describes the step-by-step process to update the UI

Declarative JavaScript (React)

// React component
function Counter() {
    // State management with useState hook
    const [count, setCount] = React.useState(0);
    
    // JSX describes WHAT the UI should look like
    return (
        <div>
            // UI automatically updates when state changes
            <div className="counter" style={{ color: count > 0 ? '#2c3e50' : count < 0 ? '#e74c3c' : '#2c3e50' }}>
                {count}
            </div>
            <div className="buttons">
                <button className="btn-primary" onClick={() => setCount(count + 1)}>
                    Increment
                </button>
                <button className="btn-secondary" onClick={() => setCount(count - 1)}>
                    Decrement
                </button>
                <button onClick={() => setCount(0)}>
                    Reset
                </button>
            </div>
        </div>
    );
}

// Render the component
ReactDOM.createRoot(document.getElementById('react-root')).render(<Counter />);

Declarative Approach Characteristics:

  • You describe what the UI should look like
  • React automatically updates the DOM when state changes
  • No manual DOM manipulation needed
  • UI is a function of state - when state changes, UI updates automatically
